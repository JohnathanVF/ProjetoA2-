# 🏛️ Política Acessível

Uma plataforma web desenvolvida com o objetivo de simplificar e democratizar o acesso a informações sobre o cenário político, tornando o conteúdo compreensível e acessível para todos os públicos.

---

## 📌 Sobre o Projeto

Este projeto foi desenvolvido como **trabalho acadêmico** para a faculdade. A proposta da atividade era criar um site do zero a partir dos conceitos, técnicas e tecnologias ensinados pelo professor em sala de aula, deixando o tema livre para a escolha dos integrantes.

Escolhemos o tema **Política Acessível** por entender a importância de promover a cidadania e a transparência de forma clara, utilizando recursos visuais e navegação intuitiva.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias básicas da web:

*   **HTML5:** Estruturação semântica de todo o conteúdo e páginas.
*   **CSS3:** Estilização visual, layout responsivo e temas de cores.
*   **Git & GitHub:** Controle de versão e hospedagem do código-fonte.
